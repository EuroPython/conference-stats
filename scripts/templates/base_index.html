The goal of this project is to gather the public conference information from the many Python events we have in Europe, so new events can have a good understanding of who to contact for future sponsorship possibilities, and speakers can see past speaking opportunities.

The data also highlights the companies and organizations helping the most in Python conferences, similarly to the most active speakers.

How to contribute

For each missing conference, find the information by visiting official websites, archives, and past event pages. For sponsors, document the sponsorship tiers and costs for that year and list every sponsor with their name, website, and level. For speakers, list full name, URL (only if provided by the speaker), proposal type, title, and level.

Not enough time to gather everything yourself? Open an issue with a URL for the conference and any sponsorship or speaker details you have, so someone else can pick it up.

Read the full contribution guide and open an issue or pull request on GitHub →
